# Algoritmia - S1

Esta carpeta reúne ejercicios de algoritmia escritos en PSeInt.

## Archivos

- `PromedioNotas.psc`: valida tres notas entre 0 y 5 y calcula su promedio.
- `Propinas.psc`: calcula la propina, el total de la cuenta y el valor por persona.

- [rueda-libre-algoritmia](rueda-libre-algoritmia/README.md): ejercicios del proyecto Rueda Libre.
- [ejercicios-video](ejercicios-video/README.md): ejercicios de PSeInt y sus pruebas.
