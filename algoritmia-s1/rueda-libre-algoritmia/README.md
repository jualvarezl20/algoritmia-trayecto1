# Rueda Libre - Algoritmia

Esta carpeta contiene ejercicios sobre el alquiler de bicicletas y recorridos.

- `bitacora.md`: registra el planteamiento del problema, los cambios y pruebas realizadas.
- `algoritmos/01_cotizacion_basica.psc`: calcula el precio del alquiler según las horas.
- `algoritmos/02_cotizacion_recorrido.psc`: calcula el costo de un recorrido según el número de personas.
- `algoritmos/03_cuenta_grupo.psc`: calcula los costos del alquiler y recorrido para un grupo.
- `diagramas/01_cotizacion_basica.svg`, `diagramas/02_cotizacion_recorrido.svg` y `diagramas/03_cuenta_grupo.svg`: diagramas de flujo de esos algoritmos.
